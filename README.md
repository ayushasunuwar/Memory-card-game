# 🧠 Memory Card Game

An interactive **Memory Card Matching Game** built using **React**, designed to demonstrate core React concepts such as component-based architecture, state management, and conditional rendering.

---

## 🚀 Features
- Card shuffling on every game start
- Match detection logic
- Game state management using React Hooks
- Responsive and user-friendly interface
- Replay / reset functionality

---

## 🛠️ Tech Stack
- React
- JavaScript (ES6+)
- HTML5
- CSS3

---

## 📂 Project Overview
This project focuses on building a logic-based interactive game using React. It utilizes functional components and hooks such as `useState` to manage card states and game progress. The UI is designed to be simple, clean, and responsive.
